# publish-to-github

An agent skill that captures the end-to-end workflow for publishing a local folder (skill, script, or project) to GitHub: git init, commit, create repo, push, README, topics, release, forks, and patched re-publications.

## Install

```bash
npx skills add phycomp/publish-to-github@publish-to-github -g -y
```

## Contents

- `SKILL.md` — full workflow, prerequisites, gotchas, and examples
